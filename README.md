# 鳍点AI（DeepSeek 版）

一个不用登录 ChatGPT 账号、直接用手机控制电脑上 Codex 的小工具。
模型仍然走你电脑上配置的 DeepSeek 接口，对话、发图片、看结果、批准命令都在手机上完成。

## 它做了什么

它在你电脑上启动一个“中转服务”，并连接你电脑自带的 Codex 程序。
你的手机浏览器打开一个网页，就能：

- 新建对话、继续之前的对话
- 发送文字、上传手机里的图片
- 实时看到 Codex 的回复、命令执行和文件修改
- 需要批准的命令会弹到手机上，一键允许/拒绝
- 随时停止正在运行的任务
- AI 回复可自动/手动“朗读”（需先在电脑上启动小云离线语音服务）

所有代码和文件都只在你自己的电脑上运行，不上传任何服务器。

## 怎么启动

1. 双击 `start.bat`（如果打不开，就右键 `start.ps1` → 用 PowerShell 运行）。
2. 窗口里会显示两个地址：
   - 电脑上打开：`http://localhost:8787`
   - 手机上打开：`http://电脑IP:8787`（手机和电脑连同一个 Wi-Fi）
3. 手机浏览器打开那个地址，输入访问密码（默认 `123456`）。
4. 在手机上点「新对话」，开始使用。

注意：这个黑色窗口不能关，关掉服务就停了。

## 安装 APK（安卓手机）

文件夹里已经打好一个安卓安装包：`CodexPhoneBridge.apk`。

1. 把 `CodexPhoneBridge.apk` 传到手机上（微信/QQ 传文件、数据线、网盘都行）。
2. 在手机上点击安装。第一次安装如果提示“未知来源”，允许即可。
3. 打开 App，第一次会要求选择连接方式：
   - 「局域网连接」：手机和电脑连同一个 Wi-Fi 时用，填启动窗口里的地址，例如 `http://192.168.2.161:8787`
   - 「中继连接（流量可用）」：在户外、用手机流量也能用，填启动窗口里显示的「配对码」和访问密码
4. 保存后就能用了，以后每次打开直接进对话界面。

顶部有「刷新」和「设置」两个按钮，设置里可以随时改电脑地址，也可以开关「自动朗读 AI 回复」。

## 检查更新（一键更新）

手机 App 的设置里有一行「更新地址」和一个「检查更新」按钮。要让“一键更新”生效，需要把新版本文件放到一个固定网址上（推荐免费注册 GitHub，用它的 Releases 功能），然后把 version.json 的网址填到：

- 手机 App 设置 → 更新地址
- 电脑 `config.json` → `updateUrl`

version.json 的内容格式：

```json
{
  "version": "1.3",
  "pcZip": "https://你的网址/电脑端.zip",
  "apk": "https://你的网址/手机.apk"
}
```

电脑启动时会自动检查并提示新版本；手机点「检查更新」会提示，并直接打开新版 APK 的下载安装页面。

## 一键发布到 GitHub（推荐）

电脑端文件夹里已经放好 `publish-update.ps1` 脚本，它会自动完成：创建公开仓库、把更新地址写进 config.json、生成新的电脑端压缩包、上传 version.json、发布 Release 并上传两个安装包。

你只需要三步：

1. 安装 GitHub 命令行工具（在自己电脑的终端里运行）：
   `winget install --id GitHub.cli`
2. 登录一次：
   `gh auth login`
3. 运行脚本：右键 `publish-update.ps1` → 用 PowerShell 运行

脚本会自动从你的 git 配置读取 GitHub 用户名（当前是 `oen1day`）。如果不对，会提示你手动输入。
运行完成后，把脚本最后打印的那个网址填进手机 App 设置 → 更新地址即可。
注意：解压后的文件夹里已经包含手机 APK，脚本会把它和电脑端压缩包一起上传，不需要你另外准备文件。

## 手机用流量（在外面）能不能连？

能，这个版本已经内置了“中继”功能：

1. 电脑上照常双击 `start.bat`，记下窗口里的「配对码」和「密码」。
2. 手机 App 里选择「中继连接（流量可用）」，输入配对码和密码。
3. 之后不管手机用 Wi-Fi 还是流量，都能连上电脑的 Codex。不需要公网 IP、不用买服务器、也不用再装 Tailscale。

说明：中继模式的消息会经过一个免费公共中继服务器，内容已经用你的密码加密，别人看不到；速度取决于中继服务网络。

备选（更稳定，但要装一个免费软件）：Tailscale

1. 电脑装 Tailscale（https://tailscale.com/download），用你的账号登录。
2. 手机装 Tailscale App，登录同一个账号。
3. 登录后电脑会得到一个 `100.x.x.x` 的虚拟地址（在 Tailscale 界面里能看到）。
4. 手机 App 选择「局域网连接」，地址填 `http://100.x.x.x:8787`。

## 修改设置

用记事本打开 `config.json`：

- `password`：访问密码，改成你自己的（重要）
- `port`：端口，默认 8787
- `workspace`：Codex 的工作目录（首次运行默认取“用户目录/Documents/Codex”，可自行修改）
- `model`：模型名，留空就是用你电脑上配置的默认模型（DeepSeek）
- `approvalPolicy`：
  - `on-request`：每个要权限的命令都会问你（推荐）
  - `never`：不询问，直接执行（方便但危险）
  - `reject`：一律拒绝
- `sandbox`：
  - `workspace-write`：只能改工作目录里的文件（推荐）
  - `danger-full-access`：可以操作整台电脑（危险）
  - `read-only`：只能读不能改
- `transport`：`spawn`（默认，自己启动 Codex）；`proxy`（连接已经运行的 Codex 服务，适合高级用户）
- `relayEnabled`：是否开启内置中继（默认开启，手机流量连接用）
- `relayBroker`：中继服务器地址，一般不用改
- `relayRoomCode`：手机配对码，程序会自动生成，也可以自己改成六位字母数字

改完保存，重新运行 `start.bat`。

## 电脑上的配对码在哪里看？

双击 `start.bat` 后，窗口里会显示一行「手机配对码(流量用): XXXXXX」，这就是手机 App 中继连接要填的配对码。
配对码在 `config.json` 的 `relayRoomCode` 里，也可以手动改成你自己喜欢的六位字母数字。

## 常见问题

**手机打不开网页**
确认手机和电脑在同一 Wi-Fi，且电脑防火墙允许 8787 端口（第一次运行如果弹出防火墙提示，点允许）。

**显示“Codex 连接失败”**
确认 `config.json` 里的 `codexPath` 留空（程序会自动找），并确认电脑上安装的是新版 Codex 桌面软件。

**为什么和电脑桌面上的对话不是同一个？**
这个工具默认使用自己新建的对话，方便起见和桌面软件互不干扰。它用的工作目录和模型（DeepSeek）和桌面端一致。

## 公开版说明（v6.0）

- 首次运行：若 `config.json` 不存在，程序会自动生成配对码、随机访问密码和配置密钥，并写入 `config.json` 与 `~/.codex/phone-bridge-id.json`；已有配置会原样沿用，不会重置。
- 新手机一键配置：启动后在黑色窗口复制“一键配置密钥”，手机 App 首次界面输入该密钥即可自动完成配对码/密码/更新地址配置。
- 发布包只包含 `config.example.json` 模板，不包含真实凭据；请勿把 `config.json`、`paths.json`、`debug.keystore` 提交到公开仓库。
- 安全提示：请定期更换访问密码；不要把 `config.json` 和密钥发给不信任的人。
